# 迷宫塔防 · Maze Tower Defense

一个**单文件、零依赖**的浏览器塔防游戏。地图完全开放，**路径由你自己砌** —— 用路障和炮台围出一条蛇形长廊，让怪物在你的火力网里多绕几圈。

> 🎮 **在线试玩**：https://jlun0854-sys.github.io/tower-defense-demo/
>
> 打开就能玩，电脑手机都行，不用装任何东西。

---

## ✨ 特点

- **自建迷宫** —— 24×15 格全是你的画布，一格固定障碍都没有
- **流场寻路** —— 怪物用 BFS 流场实时重算路线，你放下东西的**那一瞬间**它们就改道
- **防封路保护** —— 放置前会模拟计算，堵死路线直接拒绝并提示
- **无尽模式** —— 波次无上限，血量指数增长，每 5 波来一个首领
- **后期经济** —— 超载核心 / 狂暴 / 自动换分，解决"钱花不完"
- **自动存档** —— 关掉页面回来接着打，记录历史最高分
- **手机可玩** —— 横屏专属布局、触屏两段式建造、可缩放、刘海屏适配

## 👾 怪物

| 怪物 | 特点 |
|---|---|
| 小兵 | 基础单位 |
| 疾行者 | 速度快，血量低 |
| 重装 | 移动慢，**带护甲** |
| 狂徒 | 血厚甲厚 |
| 首领 | 每 5 波出现，漏掉扣 **5** 点基地耐久 |

**成长曲线**（这就是"无尽"的含义）：

```
血量    1.15^波数 × (1 + 0.01×波数)      指数增长
赏金    1.07^波数                        也是指数
速度    +0.6%/波（上限 +45%）
护甲    每 15 波 +1
```

## 🎯 战斗机制

**护甲与破甲**
普通攻击会被护甲减免（最低保留 22% 伤害）。**加农炮和激光塔无视护甲**，是后期拆重甲的唯一手段。

**暴击**
基础 12%，每过一波 +0.5%，**上限 35%**，伤害 **×3**。HUD 实时显示当前概率。

**暴走模式**
第 10 波自动触发，**所有金币收益 ×2**。

**合体塔 ⚡**
两座**相邻的、同类型的、都满级（10级）**的塔可以合体成「★ 超载塔」：

| 属性 | 倍率 |
|---|---|
| 伤害 | ×2.5 |
| 射程 | ×1.25 |
| 攻速 | ×1.3 |
| 溅射 / 穿透宽度 | ×1.25 / ×1.3 |
| 连锁 | +1 目标 |

合体后另一座塔的格子会空出来，可以再利用。外观会变大并带旋转金色光环。

## 💰 后期经济

中后期金币会多到花不完 —— 因为**塔的数量有上限（格子有限），塔的等级也有上限**，而怪物血量是无限指数增长。

所以游戏给了金币三个出口：

| 出口 | 作用 | 设计意图 |
|---|---|---|
| **超载核心** | 永久 +5% 伤害，价格 ×1.6 递增 | **主力出口**。价格和你的收入都是指数，两者赛跑，钱永远"有点不够" |
| **狂暴** | 5000 金换 10 秒攻速 ×3 | **爆发手段**。危急时刻的救命稻草 |
| **自动换分** | 金币超 2000 的部分按 100:1 转分数 | **兜底**。不想再提升了就把数字变成分数 |

> 💡 **自动换分默认关闭**，是有意的 —— 开着它买不起高级核心。想换分的时候再开。

## 💾 存档

自动存档共四个时机：

1. **每波结束**
2. **每 8 秒**
3. **切到后台**（`visibilitychange`）
4. **关闭页面**（`pagehide`，最可靠的一刻）

重新打开时会询问「继续这一局 / 重新开始」。基地被打爆时存档自动作废。

历史最高分记录在本地，HUD 上的「记录」按钮可以随时查看。

> 存档用 `localStorage`。**在 `file://` 下浏览器可能禁用**（此时用内存兜底，关掉页面存档会丢）—— 所以放服务器上玩存档才真正生效。

## 🧭 上手建议

1. **前几波先不要急着建塔**，用便宜的路障（12 金）在空地上砌一条蛇形长廊
2. **炮台放在长廊内侧**，让射程同时覆盖好几段路 —— 这是迷宫塔防的核心收益
3. **拐角处是黄金位置**，激光塔射程 268，放在长廊尽头能横跨好几条道
4. **盯着顶部的「路长」** —— 数字越大，怪物要跑的路越长，你越安全
5. 后期钱多了就买**超载核心**，别让它躺在账上

## 🛠 技术实现

- **纯单文件**：HTML + CSS + JS 全在一个 `index.html` 里，**零外部依赖、零构建步骤**
- **Canvas 2D** 渲染
- **BFS 流场寻路**：从基地向外扩散算出每格步数，怪物顺着梯度走 —— 建筑一变化就重算，天然支持动态迷宫
- **防封路判定**：放置前临时占用该格重跑一次 BFS，看出生点是否仍可达
- **分辨率无关**：逻辑坐标固定 `960×600`，靠 `ctx.setTransform` 映射到实际像素，并按 `devicePixelRatio` 渲染 —— 放到 4K 屏幕上线条依然锐利
- **响应式**：尺寸完全交给 CSS flex 分配，JS 只读取容器实测大小，不猜 `window.innerHeight`
- **刘海屏适配**：`viewport-fit=cover` + `env(safe-area-inset-*)`
- **横屏专属布局**：手机横屏时商店改为右侧竖列，把纵向空间全让给地图
